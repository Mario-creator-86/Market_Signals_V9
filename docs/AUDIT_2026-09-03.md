## 1. Harta pipeline-urilor (confirmată în cod)

### News
```
Surse: yfinance search (SPY/QQQ/DIA/IWM/VIX) → market_news
       RSS yahoo_top + marketwatch → market_news
       6 crypto RSS → market_news (is_crypto)
       Yahoo RSS per-ticker → bucket ticker (validare relevanță)
       Finnhub company news → BLOCAT: cheie lipsește (acum log WARNING clar)
       yfinance per-ticker search → flag OFF implicit (nu rulează)
       Binance/KuCoin announcements → crypto per-ticker
Agent: news_tab_agent (proces API) → dedup + validare + sentiment (FinBERT
       fallback lexicon) → data/news_backup.json; refresh 300s
Consumatori: /api/news-tab/state → UI News; news_pulse → capital gate +
       §41 AI context; hotlist_news → ticker_analyzer; pre_earnings bias
```

### Signals
```
scanner_agent → autonomous_candidates (gates) → agent_manager:
  news hydration → bot switch → size caps → RiskAgent → capital gate
  → confidence gate → autonomy gate → §41 AI → entry gate → DEBATE
  → ledger → sizing final → execution_agent → PaperBroker → capital
  position → PnL tracker → ExitManager (SL/TP/trail/time/pre-earnings
  review) → close → ledger afterward → reflection
UI: Signals Live (app.js) + Decision Ledger (cockpit.js, 13 întrebări)
```

### Pre-Earnings
```
economic_calendar (finnhub→nasdaq) + yfinance per-symbol → _load_earnings
→ canonicalizare/conflicte → scoring (gap_risk, bias, coverage) → gates
news pulse (min 3 articole/1 sursă/96h) → decizie canonică → top-10 +
pulse (snapshots/archive) → candidaty → trade flow (entry window, gates)
→ exit review post-event → close guard
UI: tab Pre-Earnings (tabel + top-10 + pulse + reported strip)
```

### Backtest / Research
```
POST /api/backtest/run → actions_service → QuickBacktester → Backtester
  (config shim cu TP/SL efectiv per combo — NOU)
POST /api/backtest/walk-forward → bucla own (selectie pe combo acum reale)
GET  /api/backtest/history (limit + include_trades — NOU)
Research Factory: scheduler/pipeline → experiments registry → cockpit
  (autoresearch KEEP/DISCARD + current best)
```
