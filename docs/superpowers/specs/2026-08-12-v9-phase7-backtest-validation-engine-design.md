# Phase 7 — Backtest & Validation Engine (V9) — Design Spec

> Spec source: `prompt_to_follow.md` §57 (Backtest Engine), §58 (Backtest Results), §59 (Walk-Forward and OOS), §60 (Overfitting Protection), §61 (No Forced Strategy). Phase 6 delivered the `OosGate` seam (`core/ml/registry.py`) whose `backtest_runner` parameter is the plug point Phase 7 fills.
> Status of this doc: design (brainstorm output). The next step is the implementation plan.

## 1. Goal

Turn the V7 backtest surface into the V9 **Backtest & Validation Engine**: a stable domain interface (`BacktestEngine`, §57) that **composes** the three existing engines behind one contract, fills the §58 metric list, defines the §59 four-way split (TRAIN / VALIDATION / OUT_OF_SAMPLE / FINAL_HOLDOUT) over the existing walk-forward + reserved-holdout primitives, adds §60 overfitting protection (purged k-fold / embargo / parameter stability / sensitivity / PBO / DSR / multiple-testing → the `ROBUST`/`MODERATE`/`FRAGILE`/`INSUFFICIENT_EVIDENCE` verdict labels that already exist as `OosVerdictLabel`), plugs the Phase 6 `OosGate` runner, and adds the §61 no-forced-strategy evidence hierarchy (TICKER→INDUSTRY→SECTOR→UNIVERSE). All additive; the existing engines, walk-forward validator, and live scanner are composed, not rewritten (§5/§7). Zero new deps (§118 — stdlib + numpy/pandas already in V7).

## 2. Scope-governing spec verbs (read literally)

- §57: **Create a stable domain interface** `BacktestEngine`. The backend **must enforce**: correct execution timing, no look-ahead, costs, slippage, spread, long, short, stop, take profit, holding period, position sizing. → Phase 7 is an **interface + adapter + metric-completion** phase, not "rewrite the backtester." The domain interface is the stable surface; the three existing engines are adapted to it.
- §58: metrics **at minimum**: the listed 27 fields (initial/final capital, net return, CAGR, benchmark, max drawdown, Sharpe, Sortino, Calmar, win rate, profit factor, expectancy, trades, avg/median/best/worst trade, holding period, exposure, turnover, fees, slippage). → Phase 7's `compute_metrics` fills the gaps the existing engines leave (CAGR, expectancy in R, median trade, exposure, turnover, fees-vs-slippage split, benchmark).
- §59: **clearly separate** TRAIN / VALIDATION / OUT_OF_SAMPLE / FINAL_HOLDOUT. **Do not optimize on final holdout.** → Phase 7 composes the existing `run_fixed_walk_forward` / `run_faithful_v2_technical_walk_forward` (TRAIN + OUT_OF_SAMPLE) + `run_reserved_holdout` (FINAL_HOLDOUT) and adds the missing VALIDATION fold as a net-new primitive.
- §60: **use where appropriate** purged k-fold, embargo, CPCV, parameter stability, sensitivity, DSR, PBO, multiple-testing safeguards. **Classify** ROBUST / MODERATE / FRAGILE / INSUFFICIENT_EVIDENCE. → Phase 7 implements the stdlib-feasible safeguards (purged k-fold, embargo, parameter stability, sensitivity, PBO, DSR, Bonferroni/Holm multiple-testing) and the verdict classifier. CPCV is implemented as a generalization of purged k-fold. **No sklearn / no new deps.**
- §61: it is **valid** to return `NO VALIDATED TICKER-SPECIFIC STRATEGY`. **Do not overfit tiny ticker histories.** Use the evidence hierarchy TICKER → INDUSTRY → SECTOR → UNIVERSE; **clearly label the evidence level.** → Phase 7 adds the evidence-level enum + the fall-through resolver; persistence of the registry is Phase 8 (§62).

## 5. Decomposition

### 7A — BacktestEngine domain interface + adapters + §58 metrics (§57/§58)

New package `core/backtest/` (no collision with the legacy `core/backtest_engine.py` / `core/backtester.py` modules):

- `types.py`
  - `BacktestExecutionTiming(str, Enum)` = `NEXT_BAR_OPEN` (the only timing the adapters enforce; the spec's "correct execution timing" = no same-bar fills).
  - `BacktestDirection(str, Enum)` = `LONG` / `SHORT` (§57 long/short).
  - `BacktestConfig` frozen dataclass: `ticker`, `asset_class`, `strategy_id` (optional), `direction` (`BacktestDirection` or `"BOTH"`), `train_range`/`validation_range`/`out_of_sample_range`/`final_holdout_range` (optional `(start, end)` tuples — the §59 split, populated by the walk-forward layer), `initial_capital`, `position_size_pct` (§57 position sizing), `commission_pct`, `tp_pct`, `sl_pct`, `max_holding_bars` (§57 holding period), `cost_model` (optional dict), `execution_timing=BacktestExecutionTiming.NEXT_BAR_OPEN`, `no_look_ahead=True` (pinned; a config with `no_look_ahead=False` raises — §57 the backend MUST enforce no-look-ahead).
  - `Trade` frozen dataclass: `entry_bar`, `exit_bar`, `entry_time`, `exit_time`, `direction`, `entry_price`, `exit_price`, `sl`, `tp`, `size`, `gross_pnl`, `commission`, `slippage_cost`, `result` (WIN/LOSS), `r_multiple`, `exit_reason`, `holding_bars`.
  - `BacktestMetrics` frozen dataclass — the §58 list, **all 27 fields**: `initial_capital`, `final_capital`, `net_return_pct`, `cagr`, `benchmark_net_return_pct` (optional — None when no benchmark supplied), `max_drawdown_pct`, `sharpe`, `sortino`, `calmar`, `win_rate`, `profit_factor`, `expectancy_r`, `num_trades`, `avg_trade_r`, `median_trade_r`, `best_trade_r`, `worst_trade_r`, `avg_holding_bars`, `exposure_pct`, `turnover_pct`, `fees_total`, `slippage_total`, `equity_curve` (tuple of floats), `validation_scope` (label string), `is_authoritative` (bool). `is_not_probability=True` pinned (a backtest metric is a realized statistic, not P(future) — §55 discipline).
  - `BacktestResult` frozen dataclass: `config: BacktestConfig`, `metrics: BacktestMetrics`, `trades: tuple[Trade, ...]`, `evidence_level` (default `EvidenceLevel.TICKER`), `no_look_ahead: True` (echoed), `raw` (the underlying engine's dict, for audit).
  - `EvidenceLevel(str, Enum)` = `TICKER` / `INDUSTRY` / `SECTOR` / `UNIVERSE` (§61).

- `engine.py`
  - `BacktestEngine` `Protocol` (the §57 stable domain interface): `run(config: BacktestConfig) -> BacktestResult`. Documented invariants: no-look-ahead (signal at bar `i` → entry at `i+1` open), costs/slippage/spread via cost model, long/short, stop/tp, holding period, position sizing. **A `Protocol`, not an ABC** — the existing engines satisfy it structurally via adapters.
  - `NoLookAheadError` — raised by adapters if the underlying engine ever fills same-bar (defensive; the faithful engine already enforces this).
  - `assert_no_look_ahead(trades, bars)` — a guard: every `entry_bar` strictly less than the bar where the signal was emitted (the adapters record the signal bar on `Trade.entry_bar` as the bar AFTER the signal; this guard verifies no trade entry precedes its signal).

- `adapters.py`
  - `FaithfulReplayAdapter` — wraps `core.strategy_backtester.backtest`. Maps `BacktestConfig` → the `backtest(...)` kwargs (ticker/days/tp_pct_override/sl_pct_override/df/config_manager/v2_only), runs, lifts the returned dict to `BacktestResult` via `compute_metrics`. `validation_scope="faithful_v2_live_replay"`, `is_authoritative=True`. The gold standard.
  - `ExploratoryEngineAdapter` — wraps `core/backtest_engine.py:BacktestEngine`. Maps config → `run_backtest(...)`, lifts `BacktestResult` (legacy) → `BacktestMetrics` (filling gaps via `compute_metrics` from the legacy trades/equity_curve). `validation_scope="exploratory_legacy_strategy"`, `is_authoritative=False`. Preserves the legacy `legacy_engine_limit` honest string in `raw`.
  - `LegacyBacktesterAdapter` — wraps `core/backtester.py:Backtester`. Maps config → `run_backtest(...)`, lifts the V1 dict → `BacktestMetrics` (fills the many gaps). `validation_scope="legacy_v1_rsi_macd"`, `is_authoritative=False`.
  - `get_default_engine()` factory → `FaithfulReplayAdapter` (the §57 default backend). Injectable for tests (fakes, no live market).

- `metrics.py`
  - `compute_metrics(trades, *, initial_capital, equity_curve=None, date_span_days=None, benchmark_equity_curve=None, validation_scope, is_authoritative) -> BacktestMetrics` — pure function, numpy/pandas only. Derives the full §58 list from a `Trade` sequence + optional equity curve. Fills the gaps the existing engines leave: `cagr` (from `net_return_pct` + `date_span_days`), `expectancy_r` (mean net R), `median_trade_r`, `best/worst_trade_r`, `exposure_pct` (sum holding bars / total bars), `turnover_pct` (sum abs position delta / capital), `fees_total` + `slippage_total` (split from commission + slippage_cost fields on `Trade`), `benchmark_net_return_pct` (from benchmark curve). Sharpe/Sortino/Calmar/win_rate/profit_factor/avg_holding_bars from the trades. **All fields computed, never None-faked**: a missing benchmark → `benchmark_net_return_pct=None` is honest (§4 — None is an honest unavailable, not a fake number); a zero-trade result → metrics are 0 with `num_trades=0` and `is_authoritative` echoed.
  - `merge_with_legacy(raw_metrics: dict, trades, *, initial_capital, ...) -> BacktestMetrics` — the existing engines produce partial metrics; this merges their values where present and fills the rest from `compute_metrics`, preferring the engine's own computation when available (no double-counting: e.g. the legacy `BacktestEngine` Sharpe is reused, not recomputed).

- `__init__.py` re-exports.

### 7B — §59 four-way split + §60 overfitting protection (§59/§60)

- `splits.py`
  - `DatasetSplit` frozen dataclass: `train_range`, `validation_range`, `out_of_sample_range`, `final_holdout_range` (each a `(start, end)` bar-index tuple), `method` (e.g. `"purged_k_fold"`, `"contiguous_walk_forward"`, `"reserved_contiguous_holdout"`). Invariants enforced in `__post_init__`: the four ranges are disjoint; `final_holdout_range` (if present) is the LAST contiguous block and does not overlap train/validation/OOS; **no range is empty except final_holdout which may be None** (§59 "do not optimize on final holdout" — it is carved off and never touches train/validation/OOS).
  - `contiguous_walk_forward_split(n_bars, *, train_bars, test_bars, max_windows, min_windows=3, warmup_bars=60) -> list[DatasetSplit]` — composes the existing `run_fixed_walk_forward` windowing into `DatasetSplit` objects (TRAIN + OUT_OF_SAMPLE; validation_range=None, final_holdout_range=None). Reuses the existing window math (no drift).
  - `add_validation_fold(split: DatasetSplit, *, validation_bars) -> DatasetSplit` — carves a VALIDATION fold out of the TRAIN block (the net-new §59 piece): TRAIN is split into TRAIN + VALIDATION (disjoint), OUT_OF_SAMPLE and FINAL_HOLDOUT unchanged. This is the primitive the existing surface lacks.
  - `reserve_final_holdout(split: DatasetSplit, *, holdout_bars) -> DatasetSplit` — composes `run_reserved_holdout`: carves the FINAL_HOLDOUT off the tail of OUT_OF_SAMPLE (or off the dataset tail), leaving TRAIN/VALIDATION/OOS untouched. Composes the existing `run_reserved_holdout` windowing.
  - `assert_disjoint_and_ordered(split)` — the §59 guard: ranges disjoint, final holdout last, no optimization on holdout.

- `walk_forward.py`
  - `run_walk_forward(ticker, df, *, config_manager, split: DatasetSplit, engine: BacktestEngine, ...) -> WalkForwardResult` — composes the adapter `engine.run` over each window (TRAIN to fit, VALIDATION to select, OUT_OF_SAMPLE to score) + `run_reserved_holdout` for FINAL_HOLDOUT. Delegates the faithful V2 path to the existing `run_faithful_v2_technical_walk_forward` when `engine is FaithfulReplayAdapter` (reuses the two-phase bootstrap+replay, NOT a reimplementation). Returns `WalkForwardResult` (frozen: `splits`, `oos_metrics: BacktestMetrics`, `holdout_metrics: BacktestMetrics | None`, `validation_method`, `validation_status`, `promotion_status`).
  - `validation_method` string: `"faithful_v2_walk_forward_v9"` (note: matches the config's `required_validation_method` prefix `"faithful_v2_walk_forward"` — the capital gate `evaluate_backtest_validation` compares with `startswith`? **No** — it compares `==`. So Phase 7 emits `"faithful_v2_walk_forward"` to stay back-compat with the capital gate, and adds a `v9_engine=True` flag. This avoids the existing naming mismatch without changing the gate.)

- `overfitting.py` (the §60 net-new surface)
  - `OverfittingVerdict(str, Enum)` — reuses `OosVerdictLabel.ROBUST/MODERATE/FRAGILE/INSUFFICIENT_EVIDENCE` (imported from `core.ml.registry`; Phase 6 defined the labels, Phase 7 defines the mapping). `PENDING`/`DEFERRED_PHASE7` are not verdicts Phase 7 emits from a classifier (they're gate states).
  - `purged_k_fold_indices(n_bars, n_folds=5, *, purge_bars=0, embargo_bars=0) -> list[tuple[train_idx, test_idx]]` — stdlib/numpy purged k-fold: standard k-fold with `purge_bars` dropped around each test fold boundary (purge) and `embargo_bars` added after each test fold (embargo, §60). Returns index pairs.
  - `parameter_stability(metric_series: list[float], *, max_relative_std=0.25) -> bool` — §60 parameter stability: a strategy is stable iff the metric (e.g. OOS profit factor across folds) has relative std ≤ threshold.
  - `sensitivity_heatmap(metrics_at_params: dict) -> dict` — §60 sensitivity: reports the metric across a parameter grid; returns the spread (max-min) and a `is_robust` flag (spread within bounds).
  - `probability_of_backtest_overfitting(is_oos_series: list[float], is_is_series: list[float]) -> float` — **PBO** (Bailey & López de Prado 2017): the probability that the IS-optimal strategy underperforms OOS. stdlib/numpy: combinatorial analysis — for each partition of {IS, OOS} across the k folds, rank strategies; PBO = fraction where the IS-best ranks below median OOS. Returns a float in [0,1].
  - `deflated_sharpe_ratio(sharpe, n_samples, n_trials=1, skew=0.0, kurtosis=0.0) -> float` — **DSR** (Bailey 2014): adjusts the Sharpe for multiple testing / non-normality. stdlib formula: `SR0 = sqrt(2*log(n_trials)) * ((1-γ)/√(2π) + γ*sqrt(2π)/2 - ... )` ... — the standard DSR formula using the Euler-Mascheroni constant γ and the standard-normal quantile. Returns the deflated Sharpe.
  - `multiple_testing_adjustment(p_values: list[float], *, method="holm") -> list[float]` — Bonferroni/Holm (§60 multiple-testing safeguards). stdlib.
  - `classify_overfitting(oos_metrics: BacktestMetrics, *, pbo: float | None = None, dsr: float | None = None, param_stable: bool | None = None, n_trials: int = 1, min_oos_trades: int = 24) -> OverfittingVerdict` — the §60 verdict classifier:
    - `INSUFFICIENT_EVIDENCE` if `oos_metrics.num_trades < min_oos_trades` (§61 "do not overfit tiny ticker histories").
    - `FRAGILE` if `pbo > 0.5` (more likely than not overfit) OR `dsr < 0` (deflated Sharpe non-positive) OR `param_stable is False` OR `oos_metrics.profit_factor < 1.05` OR `oos_metrics.max_drawdown_pct > 30`.
    - `MODERATE` if not fragile AND (`pbo in (0.25, 0.5]` OR `dsr in [0, 1.0)` OR `param_stable is True` with borderline stability).
    - `ROBUST` if `pbo <= 0.25` AND `dsr >= 1.0` AND `param_stable is True` AND `oos_metrics.profit_factor >= 1.2` AND `oos_metrics.max_drawdown_pct <= 20`.
    - Thresholds are named constants (frozen `OVERFITTING_THRESHOLDS`) so they are golden-pinnable, not magic numbers.
  - `run_overfitting_battery(oos_metrics, *, fold_metrics, param_grid_metrics=None, n_trials=1) -> OverfittingBatteryResult` — runs PBO + DSR + stability + sensitivity and returns a frozen result with the verdict + all sub-scores. This is the §60 "use where appropriate" entry point.

### 7C — OosGate runner + §61 no-forced-strategy + config + control docs (§61 + Phase 6 seam)

- `oos_gate_runner.py`
  - `OosGateRunner` — the `backtest_runner` callable the Phase 6 `OosGate.evaluate_oos_improvement` plugs in. `__init__(self, *, registry: ModelRegistry, engine: BacktestEngine, overfitting_runner, data_provider)` — injectable; tests use fakes (no live market). `__call__(self, baseline: ModelRecord, challenger: ModelRecord) -> str` — the contract:
    1. Resolve the challenger's OOS data via `data_provider(challenger)` (the `validation_range`/`out_of_sample_range` of the `ModelRecord`).
    2. Run the challenger + baseline through `engine.run` over the OOS window → two `BacktestMetrics`.
    3. Run the overfitting battery on the challenger's OOS metrics → `OverfittingVerdict`.
    4. The challenger must BEAT the baseline on OOS (e.g. `oos_metrics.expectancy_r` strictly greater) AND pass the overfitting verdict; otherwise the verdict is downgraded (a challenger that is overfit OR does not beat baseline → `FRAGILE`/`INSUFFICIENT_EVIDENCE`).
    5. Return the `OverfittingVerdict` value string. `OosGate.evaluate_oos_improvement(baseline, challenger, backtest_runner=runner)` then returns `OosVerdict(available=True, verdict=<label>, reason="phase7_runner")`, and `ModelRegistry.promote` accepts ROBUST/MODERATE.
  - `default_oos_gate_runner()` factory — wires `FaithfulReplayAdapter` + `run_overfitting_battery` + an honest `data_provider` that returns `None` (no live data in Phase 7 scope; the runner is a tested platform — real data wiring is Phase 8/11). When `data_provider` returns None → the runner returns `INSUFFICIENT_EVIDENCE` (honest, not faked).

- `no_forced_strategy.py` (§61)
  - `NO_VALIDATED_TICKER_SPECIFIC_STRATEGY = "NO_VALIDATED_TICKER_SPECIFIC_STRATEGY"` sentinel (§61).
  - `resolve_evidence_level(ticker, asset_class, *, ticker_metrics=None, industry_metrics=None, sector_metrics=None, universe_metrics=None) -> tuple[EvidenceLevel, BacktestMetrics]` — the §61 fall-through: if ticker-specific metrics are sufficient (`num_trades >= min_sample`), return `(TICKER, ticker_metrics)`; else fall through INDUSTRY → SECTOR → UNIVERSE; if none sufficient, return `(UNIVERSE, <insufficient>)` and the caller emits `NO_VALIDATED_TICKER_SPECIFIC_STRATEGY` (§61 "it is valid to return"). **Clearly labels the evidence level** on the returned `BacktestResult.evidence_level`.
  - `assert_min_sample(metrics, min_sample) -> bool` — the §61 "do not overfit tiny ticker histories" guard.

## 6. Key invariants (golden-pinnable)

1. **No-look-ahead is non-negotiable (§57).** `BacktestConfig.no_look_ahead=False` raises; `assert_no_look_ahead` rejects any trade whose entry precedes its signal. The adapters document that they delegate to engines that already enforce this (the faithful engine: signal at `i` → entry at `i+1` open).
2. **The four §59 ranges are disjoint; final holdout is never optimized.** `assert_disjoint_and_ordered` is a hard guard in `DatasetSplit.__post_init__`.
3. **§60 verdict labels are the Phase 6 `OosVerdictLabel` values.** Phase 7 imports them — it does not redefine them. The classifier is the only logic that maps metrics → labels.
4. **A backtest metric is not a probability (§55 discipline).** `BacktestMetrics.is_not_probability=True` pinned.
